## Recommended command to run the server

```
llama-server \
    -hf nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-GGUF:Q5_K_M \
    --alias dory \
    --host 127.0.0.1 \
    --port 8080 \
    -ngl 999 \
    --ctx-size 49384 \
    --parallel 1 \
    --cache-type-k q8_0 \
    --cache-type-v q8_0 \
    --flash-attn on \
    --no-context-shift \
    --jinja \
    --reasoning on \
    --no-ui \
    --temp 1.0
```
